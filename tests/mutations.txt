# =============================================================================
# tests/mutations.txt — the mutation controls for install/upgrade-full.sh.
#
# A passing test proves the code works on the inputs someone thought of. It
# does NOT prove the test would notice if the code were wrong. Each record
# below breaks one thing on purpose; tests/mutate.sh applies it to a COPY of
# the script held outside the repo, runs the covering test files, and expects
# them to go RED. A mutation that SURVIVES is a finding about the TEST.
#
# The operators are mechanical, not imagined: every comparison in the changed
# regions flipped, every guard neutralised, every returned value discarded,
# every derived constant replaced by the literal it used to be. Nothing here
# was chosen by asking what the tests would catch.
#
# FORMAT (line-oriented; everything after the first '|' is literal, so anchors
# keep their exact indentation and may themselves contain '|'):
#   --- <id>
#   DESC|<what this reintroduces>
#   TESTS|<space-separated test files that must go red>
#   EQUIV|yes|no       yes = a documented equivalent mutation, expected to live
#   ANCHOR|<exact source line>      (repeat for a multi-line anchor)
#   REPLACE|<exact replacement line>  (repeat; omit entirely to DELETE)
#
# The anchor block must occur EXACTLY ONCE in the target. Zero or two matches
# is an ABORTED control, never a pass — a mutation that did not apply proves
# nothing, and the run reports it as such.
# =============================================================================

# M45 is a DOCUMENTED EQUIVALENT, and the reason is worth keeping.
# baseline_assert_record refuses a recorded path that is a symlink AT ALL
# ([[ -L "$fp" ]]), and it runs before the chown — so with the guard in place no
# test can reach a chown on a symlink, and -h is unreachable. It stays because
# the guard and the chown are two syscalls apart: -h is what closes the window
# between them, and that race is not something a test here can create.
